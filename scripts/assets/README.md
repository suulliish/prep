# Конвейер моделей

Готовые паки (CC0: KayKit, Kenney, Quaternius) → сжатые `.glb` в `public/models`.

```
ASSET_SRC=/путь/к/исходникам node scripts/assets/build.mjs            # всё
ASSET_SRC=... node scripts/assets/build.mjs hexcore forest             # только названные наборы
```

- Исходники паков (распакованные zip) лежат вне репозитория, в `ASSET_SRC`. Пути в манифесте отсчитываются от неё.
- `manifest.mjs` — базовые наборы (герои, анимации, монстры, деревня, корабль). Наборы миров — отдельные файлы `sets/<номер>-<имя>.mjs` (экспорт `SETS`).
- Тип `kit` — много моделей в один файл: у каждой корневой узел `K_<имя файла>`; в коде `Kit.load('id').get('имя', { height, ground })`.
  Так текстура-палитра одна на набор, а в игру идёт один запрос.
- Тип `single` — отдельный файл на модель (монстры, герои), `skinned: true` для персонажей (позиции не квантуются, иначе ломается контур).
- Тип `anims` — наборы клипов скелета с выбором нужных клипов (`keep`).
- Сжатие: meshopt. Вес одного набора мира держим до ~500 КБ.

## Как добавить мир

1. Скачать нужные паки (только CC0), распаковать в `ASSET_SRC/<пак>/`.
2. Описать набор в `sets/<номер>-<имя>.mjs`, собрать `node scripts/assets/build.mjs <id набора>`.
3. Описать палитру мира в `src/three/worlds/<номер>-<имя>.ts` (`export const palette`): какие модели на каких ролях
   (ориентиры, задний план, деревья, камни, кусты, трава…), цвет земли и воды, кристаллы, доп. постановка кодом.
   Номер = индекс мира в `content/worlds.mjs`.
4. Проверить каждый из 6 уголков: `battle.html?world=<номер>&spot=<0..5>&spotSeed=<любая строка>` (см. ниже).

## Проверка

- `viewer.html?kit=<набор>&names=a,b,c&h=2` — модели набора по именам (масштаб, стоят ли на земле).
- `battle.html?world=6&layout=0&mob=0` — бой в мире: остров, декор, враг (`mob=none` — без врага, `boss=1` мини-босс, `boss=2` босс мира,
  `outfit=gold` костюм). `layout` — уголок 0..5 (0 луг, 1 лагерь на плато, 2 пруд, 3 лес, 4 руины, 5 кристаллы).
  Действия: в консоли страницы `await __w.heroAttack()`, `__w.enemyAttack()`, `__w.killMob()`, `__w.openChest()`.
