## Save v2 (save.prog; у темы topics[id].home)
```
Prog { legacy {day, coins, owned[], outfits[], styles[], worlds[], cleared[]} (один раз, первым);
  ms (вех выдано, только растёт); msDay; skins[] (legacy ∪ вехи ∪ «жарқыл» `<id>+`); frontier; worldsSeen[];
  earned: Record<ключ, монеты> (повтор не начисляет; слияние объединением); bought: Record<id,{p, day}>;
  rooms: Record<отсек, 1..4>; cards: Record<вид,{day, w, gold?}>; goldWeek; petWear {head?, neck?, back?}; petDaysBase; reserve; pastChest?; epilogue? }
```
Остаются outfit, style, world, worldsCleared (порядок = порядок побед), shipOwned, shipPet, bossTried. coins → кэш; coinsOf = legacy.coins + Σearned − Σbought.p. Устаревают xp, levelStars, DayRecord.stars, shipChestFixed.

## Функции src/engine/prog.ts (реэкспорт в rules.ts)
dengei(s) = Σ topics.lvl; holds(s) = без трещин. claimMilestone(s, day) — одна веха за заход в хаб. canEnterNew(s, day) — только при ПЕРВОМ входе в новый мир: нельзя, если трещина старше 3 учебных дней (без исключений) или ≥ 3 трещин; бывший мир не закрывается. onTopicLevel1(s, id) → home = prog.frontier. bossPool(s, w): темы с home = w и генераторами; < 4 — добор из w−1… (низкие уровни, давние проверки), ≤ 8; Башня (w=10) — 8 самых слабых из всех. bossDay(s, w, day) — 10 задач, зерно hash(day|w) (makeItem получает rng). bossVictory → {coins 45, trophy, room = ROOMS[побед−1], petForm}. earn(s, key, n, day), coinsOf, available(s, item, day), buy. Питомец: petDays = petDaysBase + будни с выполненным планом без исключения; petStage(days); petForm = worldsCleared. Коллекция: collect, goldenFor, trophyGold. Перенос: migrateProg, pastChest.
