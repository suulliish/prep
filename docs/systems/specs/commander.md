# Спецификация: командир и семейные инструменты (сжатый пересказ отчёта)

Командир — Султан (старший брат); отдельной роли «отец» нет.

## Баги (проверено)
- PIN: если не задан, его придумывает первый открывший (Commander.svelte:48), может ребёнок. «Сменить PIN» (:355) стирает PIN, а `hasPin` — константа (:25) → до выхода любой ввод «Неверный PIN». Нет лимита попыток. Хэш SHA-256 без соли (store.svelte.ts:136).
- Серия: streak.ts:9 — 2 заморозки на всю историю, а не в месяц; граница истории от attempts[0].day (а localJson хранит 12 мес.); лимит цикла 400 календарных дней → серия ≤ ~286 учебных дней (до экзамена ~410). Исключение только на сегодня (:108).
- Подарки влияют в planner.ts:75 (minutesToday) и analytics.ts:93.

## Save v2 (часть командира)
settings.pin?: {hash, salt, iter, setAt} (PBKDF2-SHA256); exceptions?: {id, from, to, kind:'sick'|'holiday', note?, at, deleted?}[]; flags?: Record<FlagId,{on, from, at}>; owner?: uid; notebook[id].shownAt?. Удаляются миграцией: days[].bonuses, days[].exception (→ exceptions, 'vacation'→'holiday'), settings.planMinutes, recallOffer[].skipped. Только на устройстве: razlom.pinGuard, razlom.profile ('main'|'twin'), отдельная ячейка двойника.

## Чистые функции
- src/engine/pin.ts: pinGuard(g, now, ok) → {g, allowed, waitMs}; hashPin(pin, salt, iter); legacyPin(save).
- src/engine/exceptions.ts: exceptionOn(save, day); isSchoolDay(save, day); addException(save, e, today) (диапазон, слияние пересечений); shiftDue(save, from, due). Контракт с расписанием: срок считается при чтении через dueOf() (исключение на будущее сдвигает уже назначенные сроки).
- src/engine/streak.ts: streak(save, today) → {days, freezesLeft}; пропуск будня без исключения тратит заморозку месяца (2/мес), граница — первый день в save.days, без лимита 400; исключения +1.
- src/engine/weekly.ts: weeklyReport(save, monday, ctx), weeklyText(r, name) (только import type, запускается в Node для report.mjs).
- src/engine/alerts.ts: alerts(save, today, ctx) → {id, level, text, phrase, since}[].
- src/engine/forecast.ts: readiness(save, defs); forecast(save, defs, today) → null | {low, high, mid, gate, gain[], projMay?}.
- src/lib/commanderAuth.svelte.ts: unlockedUntil в памяти; unlock/lock; reauth(password) (reauthenticateWithCredential); setPin(pin, password).
- src/lib/flags.svelte.ts + content/flags.mjs {id, name, visibleToChild}; canEnable(main, twin, id, today).
- src/lib/profile.ts: ключ сохранения по профилю; Firebase initializeApp(cfg, 'twin') — оба аккаунта вошедшими на телефоне Султана.

## Готовность и прогноз (только командиру)
Разделы A–J (K в A), без чтения; EXAM_Q {A 8.5, B 6.5, C 7, D 3.5, E 7, F 4, G 3.5, H 1.5, I 3.5, J 5} = 50; готовность = доля тем раздела с уровнем ≥ 2 без трещины (знаменатель — все темы). Прогноз после ≥ 28 дней, ≥ 15 дней с планом, ≥ 20 проверок; бета-сглаженная точность проверок раздела за 8 недель; q·r·(5a−1); нижняя граница — уровень ≥ 3 и a P10, верхняя — уровень ≥ 1 и a P90; [0, 200], округление до 5; «сегодня 95–130 из 200 (матем.+логика; чтение не готовим)», цель 180, «добрать: A +14…». Через 8 недель — строка «к маю 2028». При ≥ 2 полных пробниках за 60 дней — главным средний балл пробников.
