## 2. Обучение (как тема становится экзаменной)

**Сохраняем:** строгую модель освоения (окно 85%), чередование задач, метки ошибок, скелет урока, «Бит помогает только после попытки», «Білмеймін» = 0.

**Исправляем сразу (движок врёт в пользу спешащего):**
1. Быстрый неверный ответ — это **неверный ответ** для модели знаний. «Нечестно» влияет только на минуты и монеты.
2. Ответы урока записываются в историю (с метками ошибок).
3. Финал урока — **новая задача того же типа**, одна попытка; провал → тема завтра первой.
4. Проверка темы — **2 задачи разных типов уровня ≥ 2, до того как ребёнок вспоминает правило.** Обе верны (первая чисто) → уровень темы вверх; одна → держится, повтор через 2 дня; ни одной → трещина и правило-карточка.

**Тема от начала до экзамена:** входная проверка (знает — короткий урок) → «сначала попробуй сам» → разбор со схемой и сравнением двух примеров → пропуски с конца (3 задачи) → ошибка Глитча → 3 задачи с вводом числа → финал на новой задаче → практика лесенкой 1→2→3 → «освоено» = окно 85% + ответы уровня 2 и 3 → проверки → экзаменный формат на время (уровень 5).

**Уравнения:** весы (виджет есть) → обратные действия → x с двух сторон → скобки двумя способами → составить по словам (история → схема → символы) → проверка подстановкой.
**Текстовые:** 8 схем-полосок (часть-целое, сравнение, сумма-разность, лишнее/не хватает, возраст, части остатка, движение v·t=s, работа). Каждая задача: прочитал → «о чём вопрос?» → **выбрал тип** → заполнил схему → действие → проверка. Быстрые упражнения «только определи тип».

**Неделя:** Пн–Ср — новая тема; Чт — день схем и задач уровня 3; Пт — мини-пробник 10 задач в формате экзамена. Итого **3 новые темы в неделю**.

## 3. День ребёнка

Сейчас: 50–70 минут, 6–7 возвратов на корабль, 5–6 порталов, кнопка «дальше» ждёт до 18 с, три касания на ответ, итог после каждого шага. Внимание в 11 лет — 25–35 минут.

**Новый будний день — 25–35 минут, два «рейса»:**
- **Рейс 1 (15–20 мин):** один портал → «Тексеріс» (проверки тем по расписанию, до 6) → в день урока: урок и «Дәптер».
- **Привал:** единственный возврат на корабль, Бит: «5 минут тынығу».
- **Рейс 2 (10–15 мин):** один бой волнами: практика новой темы → смешанные → **ремонтная волна** сегодняшних ошибок («исправился — дозаработал» сразу) → один итог дня.
- Внутри рейса шаги идут подряд (герой переходит в соседний уголок мира, 1–1,5 с), без корабля и портала.
- Праздники по размеру: ответ ≤ 0,8 с; шаг ~1 с; тема выросла 2–3 с; веха/мир/босс — полная сцена раз в 1–2 недели.

**На корабле три вещи** (деңгей и следующая веха, минуты «25/60» и копилка выходных, монеты); трещины — на корабле и кнопкой «Жөндеу».

**Правила ребёнок узнаёт в момент первой встречи** (по одному в день первую неделю), плюс страница «Ойын заңдары» у героя. Вступление — 1–2 экрана.

**Выходные:** копилка минут; по желанию «Сенбі тексерісі» ≤ 5 мин (только проверки) — гасит понедельничную очередь.

**Против читерства — дизайном, а не наказанием:** оставить +1/−¼/0, близнецов, «до N верных», «читать действием» (вставить число, коснуться подсветки), фиксированного по дате босса. Смягчить: таймер чтения — запасной, до 10 с, озвученное — до конца голоса (**меняет решение 02.10, нужно согласие**); свернул приложение → задача закрывается, по возвращении близнец с новыми числами (вместо молчаливой пометки); самопроверка не на каждой лёгкой задаче; «Дәптер» без камеры — «покажу командиру»; голос никогда не запирает путь.

## 4. Прогрессия и мир

Как в `DESIGN.md` (деңгей = сумма уровней тем, не падает; трещины; 49 вех; миры по деңгею; босс по темам мира; монеты за освоение; минуты как сейчас), с уточнениями:
- Проверка темы — по правилу из раздела 2 (2 задачи до правила), а не «первая + добивочные».
- Арена (полные пробники) — **с сентября 2027**, по плану контента.
- **Сюжет на 19 месяцев:** пролог (Бит без памяти; «Биткә түсіндір» чинит его память) → осколки (боссы — прислужники Глитча) → Глитч питается забытым (трещины на островах) → карта Кода = готовность по разделам → Башня → Арена → финал — экзамен; накануне — день без задач и полёт над всеми островами; после — эпилог от командира («Сынақ тапсырылды»), без зависимости от балла.
- **Бой, где ход — это математика:** доспех босса из пластин-тем мира (бить нужным приёмом), «Бөлгіш қару» (делимость), «Таразы-қақпа» (уравнения, вместе с уроками), «Глитчтің тыңшысы» (логика: кто лжёт).
- События: Жаңа жыл, Наурыз, «Соңғы жыл» (1.09.2027), открытие арены. Бестиарий, «алтын моб», пасхалки — без случайного за деньги.
- Убираем навсегда: бойцов, карточки силы, ранги, энергию, звёзды как валюту.

## 5. Семья

**Ритм:** каждый день — 30 секунд (минуты на «Сегодня»); **воскресенье 15 минут, Султан**: недельная карточка → разговор «одна похвала за стратегию → одно действие → выбор из двух» → решения на неделю; отец — раз в месяц («деңгей · держится», разделы, прогноз диапазоном).

**Недельная карточка:** план N/5, минуты заработано/подарено, деңгей +Δ и «держится», топ-3 растущих и 1 отстающий раздел, честная работа и тренд, трещины, точность проверок, ≤ 2 тревоги с готовой фразой, запас уроков в неделях, сбои и синхронизация. Сначала вкладка «Неделя» + «Поделиться» в Telegram; потом сама приходит в воскресенье 19:00.

**Тревоги:** 2 дня без плана; честность < 70%; частые сворачивания; «Білмеймін» > 30%; провалы проверок > 40%; трещина старше 7 дней; подарков > 30 мин в неделю; запас уроков < 3 недель; нет синхронизации > 3 дней.

**Правила:** зашитое (60 минут, −¼, 85%, интервалы, пропусков нет, монеты за освоение) меняется только записью в `DECISIONS.md` и с понедельника; командир настраивает доп. миссию, голос/фото, исключения (в том числе на будущие даты), темп 2–3 темы, назначение темы, подарки — каждое изменение пишется в журнал с автором (Султан / отец).

**Срочно:** PIN нельзя придумать ребёнку (только через пароль облака), задержка после 5 ошибок, смена PIN не ломает вход, подарки с лимитом и причиной, исправить устаревшие подписи.

## 6. Техника

**Срочно — прогресс может пропасть уже сейчас:**
1. **Старая копия на другом телефоне перезаписывает облако** (у брата приложение висит в фоне несколько дней → он дарит минуты → его старое сохранение уходит в облако → у ребёнка откатываются темы, дни, монеты). Исправление: перечитывать облако при возврате в приложение, запись через транзакцию, слияние по полям (уровни тем — максимум, открытое — объединение).
2. Ответы одного месяца с двух устройств затирают друг друга — сливать перед записью.
3. Опечатка в почте молча создаёт новый пустой аккаунт — убрать автосоздание.
4. Сервер Бита: выставить список своих аккаунтов (`ALLOW`), таймаут 120 с, бюджет и оповещение.

**Скоро:** офлайн-кэш с версией и очисткой (иначе растёт на сотни МБ и браузер может стереть сайт), голос и модели с хэшем; память браузера переполнится к середине 2027 → ответы в IndexedDB; 3D не рисует под уроком и при свёрнутом приложении, 30 кадров на слабых телефонах; главный файл 2,5 МБ → < 600 КБ (банк, 3D и уроки отдельными кусками); версия сборки видна командиру и пишется в ошибки; правила Firestore в репозиторий; smoke-тест в CI.

**Данные v2:** `topics` (уровень, лучший, срок, трещина), `unlocked` (только растёт), вехи, журнал монет; облако — ядро ≤ 150 КБ, дни и журнал ИИ — в подколлекциях. Перенос идемпотентный, сначала только добавляет поля; чистка старого — через ≥ 4 недели.
