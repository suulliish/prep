## 1. Словарь: одно определение на понятие

Код реализует каждое понятие **одной функцией** (`src/engine/rules.ts`, этап 1); экраны и командир только вызывают её.

| Понятие | Определение |
|---|---|
| **Наспех** | ответ быстрее личного порога (`rush.ts`); касается и верных, и неверных |
| **Честный ответ** | не наспех, без полного разбора, приложение не свёрнуто дольше 5 с. Нечестный ответ не даёт минут и монет |
| **Ответ для модели знаний** | любой ответ с первой попытки без подсказки; **ответ наспех тоже идёт в модель** (неверный — как неверный, верный наспех — не засчитывается как верный). Ответы урока тоже идут в историю (`mode: 'lesson'`) |
| **Свернул / бросил задачу** | > 5 с вне приложения или выход из шага → задача закрыта и считается **неверной**; дальше — близнец с новыми числами |
| **Қиындық** | сложность задачи генератора 1–3 (не путать с уровнем темы) |
| **Уровень темы 0–5** | 0 нет урока · 1 **үйренді** (окно 85% + верные қиындық 2 и 3) · 2/3/4 проверки через 1 нед / 3 нед / 2 мес · 5 **дайын** (верно с первой попытки в мини-пробнике или пробнике, не быстрее мин. времени) |
| **Проверка** | 2 задачи разных типов қиындық ≥ 2 до вспоминания правила; обе верны (первая чисто) → вверх; одна → держится, повтор через 2 учебных дня; ни одной → трещина. Сгорает при показе первой задачи |
| **Трещина** | проверка «ни одной»; тема не растёт, ежедневно в «Тексеріс» |
| **Починка** | практика сегодня + проверка на следующий учебный день → прежний уровень, интервал заново |
| **Интервалы** | календарные дни, срок — на ближайший учебный день; в каникулы и исключения сроки стоят |
| **Деңгей / держится** | Σ уровней тем / Σ уровней тем без трещин |
| **Готовность раздела** | доля тем раздела с уровнем ≥ 2 и без трещины, с весом раздела на экзамене |
| **Веха / мир / арена** | `DESIGN.md` §4–5: 49 вех; пороги миров — вехи; арена по дате 1.09.2027 |
| **Минуты** | решение семьи 02.10 «точность стоит, труд возвращает»: во время плана +1 / −¼ / 0; потерянное возвращается ремонтом в конце рейса 2 (ошибка → 2 верных близнеца, «Білмеймін» → объяснение + 1 близнец) до полных 60; застрял → проще задачи; 50 мин честной работы → 60, остаток ремонта — завтра первым; доп. миссия +15 по тому же правилу; копилка выходных ≤ 90; засчитываются после итога рейса 2 |
| **Серия** | будний день с выполненным планом; исключения не рвут; 2 заморозки в месяц |
| **Балл пробника / прогноз** | шкала 240 (+4/−1); прогноз = по пробникам, пока их мало — готовность разделов × веса; всегда диапазоном; только командиру (ребёнку — диапазон пробника с разбором) |

## 2. Экзамен и контент

**Известно:** один тур, 60 вопросов за 110 минут (50 математика и логика + 10 чтение; **чтение не готовим — только математика и логика, решение семьи 02.10**), 5 вариантов, +4 / −1, максимум 240; регистрация 1.02–апрель на bilemtihan.kz; экзамен в середине мая. Проходные 2025: Астана (мальчики) 206, Аксай 196, Есик 158; **Өскемен — неизвестно**. Рабочая цель — **180**.

**Звонок в лицей** (8 7232 25-29-62, oskemen.er@bil.edu.kz): проходной и мест в 7 класс (казахский поток) за 2025–2026; бумага или компьютер, черновик; шкала +4/−1; пробники для пятиклассника; квоты.

**Пробелы:** уравнения (≈35 баллов), текстовые (≈28), геометрия (≈26) — ноль уроков; десятичные — ни уроков, ни генераторов. Банк не размечен по темам; 53 id в генераторах не совпадают с графом. Порядок тем сейчас задаёт класс/вес, а не план → нужна **явная очередь тем**.

**Темп (решение семьи 02.10):** новые темы — **до середины ноября 2027**, последние полгода — только практика. Это ≈ 135 тем за ≈ 55 недель → **3 новые темы в неделю** (летом меньше). Кончились уроки — делаем новые: уроки пишутся с опережением ≥ 3 недели, планировщик не ждёт. Новая тема даётся, только если две предыдущие үйренді (иначе день практики) — темп сам падает, когда трудно.

Брат только проверяет. Носитель: **разово 6–8 часов** на 36 старых уроков (≈10,5 тыс. слов, по очереди «к которой подходит ребёнок») + **≈ 2 часа в неделю** до ноября 2027. Тесты контента: запас уроков ≥ 3 недели; у темы ≥ 2 генераторов, один қиындық ≥ 2; банк размечен по темам; сборщик пробника держит веса; `kzReview` у каждого урока.

**Чтение:** не готовим (решение семьи 02.10) — только математика и логика.

## 3. Обучение

**Сохраняем:** строгое окно 85%, чередование, метки ошибок, скелет урока, Бит помогает только после попытки, «Білмеймін» = 0.

**Тема от начала до экзамена:** входная проверка (знает — короткий урок) → «сначала попробуй сам» → разбор со схемой и сравнением двух примеров → пропуски с конца (вписать число) → ошибка Глитча → 3 задачи с вводом числа → финал на **новой** задаче того же типа, одна попытка (провал → тема завтра первой) → практика лесенкой қиындық 1→2→3 → үйренді → проверки → пробник (дайын).

**Ошибки лечатся:** метка ошибки повторилась 2 раза за неделю → короткое объяснение Бита на контрасте + 2 задачи с той же ловушкой; уверенные ошибки — первыми.

**Уравнения:** весы → обратные действия → x с двух сторон → скобки двумя способами → составить по словам (история → схема → символы) → проверка подстановкой.
**Текстовые:** 8 схем-полосок (часть-целое, сравнение, сумма-разность, лишнее/не хватает, возраст, части остатка, движение v·t=s, работа). Каждая задача: прочитал → «о чём вопрос?» → тип → схема → действие → проверка. Упражнения «определи тип» — с обманчивыми словами, после выбора — заполнить одну клетку схемы; минут не дают.

**Неделя (будни):**

| Пн | Вт | Ср | Чт | Пт |
|---|---|---|---|---|
| новая тема | практика + схемы | новая тема | новая тема (если две предыдущие үйренді, иначе практика) | мини-пробник 10 задач (с декабря) + разбор |

**Каникулы:** неделя отдыха в осенние, зимние и весенние каникулы (только «Тексеріс» по желанию); летом — 2–3 недели полного отдыха.

## 4. День ребёнка

Сейчас 50–70 минут, 6–7 возвратов на корабль, кнопка «дальше» ждёт до 18 с, итог после каждого шага. Внимание в 11 лет — 25–35 минут.

**Будний день — 25–35 минут, два рейса:**
- **Рейс 1 (15–20 мин):** один портал → «Тексеріс» (проверки по сроку, до 6 тем) → в день новой темы: урок и «Дәптер».
- **Привал:** 5-минутный таймер в игре (можно начать рейс 2 сразу). Минуты дня засчитываются только после итога рейса 2.
- **Рейс 2 (10–15 мин):** один бой волнами: практика новой темы → смешанные → ремонтная волна сегодняшних ошибок → один итог дня.
- Внутри рейса шаги идут подряд (соседний уголок мира, 1–1,5 с) без корабля и портала.
- Праздники по размеру: ответ ≤ 0,8 с; шаг ~1 с; тема выросла 2–3 с; веха, мир, босс — полная сцена.

**Правила ребёнок узнаёт в момент первой встречи** (одно в день первую неделю) + страница «Ойын заңдары» у героя; вступление — 1–2 экрана.

**Выходные:** копилка минут, мастерская, альбом. Плана нет.

**Против читерства — дизайном:** +1/−¼/0; близнецы; «до N верных»; «читать действием», которое требует понимания («о чём спрашивают?» с ловушками, а не «найди число»); таймер чтения — запасной, до 10 с, озвученное — до конца голоса; свернул/бросил → задача неверна + близнец; самопроверка — на случайных задачах; босс и проверка сгорают при показе; неверный приём в бою = потерянный ход; «Дәптер» без камеры — «покажу командиру», но 3 непоказанные страницы подряд → снова только фото; голос никогда не запирает путь.

## 5. Прогрессия, мир и сюжет

Прогрессия — `DESIGN.md` v5 (деңгей, уровни тем, трещины, 49 вех, миры по вехам, босс по темам родного мира, монеты, серия, перенос).

**Сюжет на 19 месяцев:** пролог (Бит без памяти; «Биткә түсіндір» — часть урока — чинит его память) → осколки (боссы — прислужники Глитча) → «Глитч питается забытым» (трещины на островах) → карта Кода = готовность по разделам → Башня → Арена → финал — экзамен; накануне — день без задач и полёт над всеми островами; после — эпилог от командира («Сынақ тапсырылды»), не зависит от балла. Бит говорит, что забывать нормально; обратный отсчёт до экзамена видит только командир.

**Позже, если упадёт интерес:** доспех босса из пластин-тем, бои «Бөлгіш қару» (делимость), «Таразы-қақпа» (уравнения), «Глитчтің тыңшысы» (логика), бестиарий, «алтын моб». **События:** Жаңа жыл, Наурыз, «Соңғы жыл», открытие арены. **Убрано навсегда:** бойцы, карточки силы, ранги, энергия, звёзды как валюта.

## 6. Семья

**Ритм:** каждый день — 30 секунд (минуты на «Сегодня»); **воскресенье, Султан, 15 минут** (5, если тревог нет): карточка недели → ребёнок пишет одну строку «что было трудно» → разговор «одна похвала за стратегию → одно действие → выбор из двух» (цифры тревог ребёнку не зачитываются, только готовая фраза) → решения на неделю. **Отец** — раз в месяц: «деңгей · держится», разделы, прогноз диапазоном.

**Карточка недели** (вкладка «Неделя» + кнопка «Поделиться» в Telegram): план N/5, минуты заработано/подарено, деңгей +Δ и «держится», топ-3 растущих и 1 отстающий раздел, честная работа, трещины, точность проверок, непоказанные страницы «Дәптер», запас уроков в неделях, сбои и синхронизация, тревоги с готовой фразой.

**Тревоги (5):** 2 дня без плана; честность < 70% за 3 дня; трещина старше 7 дней; запас уроков < 3 недель; нет синхронизации > 3 дней.

**Правила:** зашитое (минуты, −¼, 85%, интервалы, пропусков нет, монеты за освоение) меняется только строкой в `DECISIONS.md` и с понедельника; командир настраивает доп. миссию, голос/фото, исключения (и на будущие даты, и диапазоны каникул), темп 2–3 темы, назначение темы.

**Срочно:** PIN нельзя придумать ребёнку (задаётся только с паролем облака), задержка после 5 ошибок, смена PIN не ломает вход, разблокировка на 10 минут; исправить устаревшие подписи.

## 7. Техника и безопасность изменений

**Срочно — прогресс может пропасть уже сейчас** (проверено в коде): облако читается только при запуске (`src/lib/cloud.svelte.ts:121`), а запись перезаписывает главный документ целиком без проверки (`:62`). Если у брата приложение несколько дней висит в фоне и он дарит минуты, его старая копия уходит в облако, и у ребёнка при следующем запуске откатываются темы, дни, монеты (ответы — нет, они сливаются). Исправление: перечитывать облако при возврате в приложение; запись через транзакцию; слияние по полям. Ещё: опечатка в почте молча создаёт новый аккаунт (`:150`) — убрать.

**Защита каждого релиза:** версия приложения в сохранении; клиент, увидевший более новую схему, не пишет в облако и просит обновиться; ежедневный снимок сохранения в облаке (14 дней) и восстановление кнопкой; обезличенная копия сохранения ребёнка как фикстура тестов; **тестовый аккаунт-двойник** на телефоне брата и флаги функций — новое сначала двойнику 3–5 дней, потом ребёнку **в понедельник**; новые расчёты сначала в тени (видит командир); **ребёнку — не больше одного заметного изменения в неделю** (контент не считается).

**Скоро:** офлайн-кэш с версией и очисткой (иначе растёт на сотни МБ), голос и модели с хэшем; 3D не рисует под уроком и при свёрнутом приложении; версия сборки у командира и в ошибках; правила Firestore в репозитории; smoke-тест в CI. **Позже, по необходимости:** разделение кода, IndexedDB, подколлекции дней (чистки полей хватает: ~350 КБ к экзамену).
