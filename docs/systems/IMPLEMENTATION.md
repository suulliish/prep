### 1.1 Функции (живут в `src/engine/rules.ts`, другие модули реэкспортируют)

|---|---|---|

| свернул | `isClosed(awayMs)` | > `AWAY_CLOSE_MS` 5000, **включая фазу чтения условия**; пишется `Attempt.closed = true` + существующее `Attempt.away` (мс) |

### 1.3 Решения консилиума внутри решений Султана

1. **Уровни тем — свёртка из ответов** (`foldTopics`), `topics` — кэш; `topicsBase` при слиянии — более ранний `at`. Сгорание проверки пишется ответом (`mode 'check'`, неверно при показе), чтобы свёртка его видела. **Родной мир темы — `prog.home{тема: мир}`**, побеждает первый (из ответов не выводится).
2. **Прогрессия — `save.prog`** (P); поля `unlocked/milestones/ledger/pets/collection/repairQueue/rulesV` из `data.md` не заводим.
3. **Ремонт минут — `save.debts`** (D).
4. **Минуты начисляются один раз** в итоге рейса 2; при слиянии устройств — более раннее начисление целиком. **День закрепляется при старте рейса 1**; начислить можно до 01:00, если рейс 2 начат до полуночи; `game.day` меняется только на корабле. Рейс 2 не пройден → 0, долги переносятся.
5. **Два устройства в один день**: честное время — интервалы с объединением (не сумма); `slotId` содержит `planId`; рейс 2 на другом устройстве — только после синхронизации рейса 1.
6. **Перезагрузка не меняет задачу**: задача по зерну слота, после восстановления та же; `hiddenAt` пишется синхронно на `visibilitychange` и `pagehide`; падение без `hiddenAt` → та же задача (если < 10 мин), иначе ошибка.
7. **Часы**: смещение по `serverTimestamp`; часы ушли назад — начисления нет; начисление без сети «не подтверждено», копилка и питомец считают подтверждённые.
8. **«Білмеймін» на всё**: близнецы за «Білмеймін» — в конце ремонта и другим шаблоном; после 6 «Білмеймін» за день — по 2 близнеца; тревога командиру.
9. **«Нажми на число»** — засчитывается первое касание; ошибка → Бит перечитывает.
10. **Трофей**: босс даёт сундук (45), отсек, форму питомца; **трофей мира — за всю коллекцию видов мира** (как решил Султан).
11. **Флаги** — один документ `users/{uid}/meta/flags`; кэш флагов, базы слияния и usage — с ключом uid; `owner` проставляется при первой загрузке после S2.
12. **Восстановление снимка** берёт из снимка только немонотонные поля; монотонные (`prog.earned/bought/skins`, дни питомца) и сегодняшний день — объединение.
13. **Переход 30.11 в два шага**: 23.11 — сохранение v2 без изменений экранов; 30.11 — интерфейс. До S13 клиент v2 **дублирует запись в поля v1** (монеты, статусы, XP), поэтому выключение флага — настоящий откат.
14. **Казахский**: файл `content/kz_review.json`; черновики ребёнок видит, «түзету» — нет; разово проверяются 36 старых уроков и строки интерфейса (≈ +3 ч до 23.11).
15. **Караоке**: один формат времён слов `public/voice/lessons/<id>.json {w, t0, t1}[]` из `make_voice.py`.
