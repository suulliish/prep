# Дизайн-система «Жарық»

Версия 2 (28.09.2026). Заменяет «голографическую консоль» v1. Токены и компоненты — `src/app.css`, каркас — `src/ui/Screen.svelte`,
иконки — `src/ui/Icon.svelte`. Любой новый экран собирается только из того, что описано здесь.

## 1. Почему так

Ученику 11 лет. Он играет в Brawl Stars, Clash Royale, Minecraft, Roblox — у него уже есть «глаз» на то, как выглядит
настоящая игра. 3D-мир у нас в том же стиле (мультяшные кубики с контуром), а интерфейс v1 был тёмной sci-fi консолью с
пиксельным шрифтом: мелко, темно, не похоже на игру. v2 — **интерфейс в стиле Supercell**: объёмные «игрушечные» кнопки с
толстым тёмным контуром, яркие панели, крупный жирный шрифт, светлые карточки для чтения.

## 2. Пять правил

1. **Одна главная кнопка — внизу, под большим пальцем.** Всегда видна без прокрутки. Жёлтая. Одна на экран.
2. **Задачу читают на светлой бумаге.** Условие, варианты, объяснение — тёмный текст на светлой карточке (как в учебнике),
   игра — вокруг. Математику никогда не пишем светлым по тёмному мелко.
3. **Ничего не молчит.** Каждое касание отвечает: звук + движение. Закрытое выглядит закрытым (замок) и при нажатии
   объясняет, что нужно сделать.
4. **Сцена видна целиком.** 3D-мир живёт в своём окне сверху; панели его не перекрывают, герой и враг в кадре полностью.
5. **Казахский, коротко, глаголом.** «Бастау», «Тексеру», «Келесі». Цифры крупно. Без русских слов на детских экранах.
   Слова: босс = «бас жау» (мини-босс = «күшті жау»), энергия = «қуат», мини-игра = «шағын ойын». Имя злодея «Глитч» остаётся (это имя, не слово).

## 4. Шрифты

| Роль | Шрифт | Где |
|---|---|---|
| Заголовки, цифры, кнопки | **Rubik** 800/900 | названия экранов, счётчики, текст кнопок |
| Текст | **Nunito** 700/800 | всё остальное |

Оба содержат все казахские буквы (проверено по файлам шрифтов: ә ғ қ ң ө ұ ү һ і). Пиксельный Tiny5 — только логотип.

Шкала (телефон): `--t-xs` 13 · `--t-s` 15 · `--t-m` 17 (текст) · `--t-l` 20 (условие задачи) · `--t-xl` 26 (заголовок) ·
`--t-xxl` 34 (большие числа). Минимум на детских экранах — 13px. Заголовки на панелях — с «игровым» контуром
(`text-shadow` в цвет `--outline`).

## 5. Форма

- **Контур** 3px `--outline` у кнопок и панелей — главный признак стиля.
- **Ступенька**: кнопка стоит на «полке» `0 5px 0 <edge>`; при нажатии опускается на 4px (0.1с). Панели: `0 6px 0 #0008`.
- **Радиусы**: кнопки 14px, панели 20px, бумага 14px, пилюли 999px.
- **Отступы**: 4 · 8 · 12 · 16 · 24. Внутри панели 14–16px, между блоками 12px.
- **Касание**: цель ≥ 48×48px, между целями ≥ 8px.
- **Слои (z-index)**: 3D 0 · окно экрана 10 · всплывающие подписи 20 · нижняя панель действий 30 · тост 40 · модалка 50.

## 6. Каркас экрана (`src/ui/Screen.svelte`)

```
Телефон (портрет)                      Широкий экран (≥1000px, альбомный)
┌──────────────────────────┐          ┌──────────────────┬───────────────┐
│ ‹  Заголовок      [ресурс]│ шапка    │                  │ ‹ Заголовок   │
├──────────────────────────┤          │                  ├───────────────┤
│                          │          │    3D-сцена      │               │
│   окно 3D-сцены          │ 34–40%   │    (герой,       │  панель       │
│   (герой и враг целиком) │          │     враг)        │  (прокрутка   │
├──────────────────────────┤          │                  │   внутри)     │
│ панель: прокрутка внутри │          │                  │               │
│  бумага с задачей        │          │                  ├───────────────┤
│  варианты ответа         │          │                  │ [ГЛАВНАЯ]     │
├──────────────────────────┤          └──────────────────┴───────────────┘
│ [ ГЛАВНАЯ КНОПКА ]       │ прибита к низу
└──────────────────────────┘
```

- Страница целиком **не прокручивается**; прокручивается только тело панели. Шапка и главная кнопка всегда на месте.
- Высота окна сцены задаётся экраном: `scene="tall"` (40%, итог), `"short"` (30%, урок), `"strip"` (практика/бой),
  `"fill"` (главный экран: окно забирает всё, что не занял компактный низ, то есть ≥ 50% высоты), `"none"` (альбом, командир — сцена за размытием).
- Если в теле панели есть что прокрутить, над главной кнопкой видна тень и прыгающая жёлтая стрелка (`.more` в Screen.svelte).
  Варианты ответа никогда не прячутся под кнопкой: кнопка не перекрывает тело, а стоит под ним отдельной строкой.
- **Телефон в горизонтали** (ширина < 1000, высота ≤ 560): `html.lsplit` — 3D-canvas сужается до левой части экрана
  (`canvas.world` в app.css, ширина `100% - --lp-w`), справа колонка: компактная шапка → панель → кнопка. Мир сам считает кадр по
  размеру canvas, поэтому герой стоит по центру видимой сцены (world.ts менять не пришлось). Реплика Бита в этом режиме — поверх
  сцены; в портрете — в панели под вариантами (сцену не закрывает).
- Числа в тексте и плитках склеиваются неразрывными пробелами (`nb()` в `src/ui/text.ts`): «648 210 060» не рвётся на две строки.
  Длинные числа (≥ 10 знаков) в узкой панели идут в одну колонку.
- Камера каждого режима настраивается так, чтобы её цель была **в центре окна сцены**, а не экрана
  (`setFrame(top, height)` в `src/three/world.ts`).

## 8. Иконки

Свои SVG 24×24 (`src/ui/Icon.svelte`): back, sound, sound-off, gear, map, hero, cards, clock, crystal, fire, bolt,
lock, check, cross, star, play, sword, book, flag. Заливка + контур `--outline` 2px, как у кнопок. Эмодзи в интерфейсе нет.

## 9. Движение и звук

- Нажатие: 100мс вниз, 150мс назад. Появление карточек: 250мс снизу. Верно: зелёная вспышка + звук + удар по врагу.
  Неверно: лёгкое покачивание 300мс, коралл, без «наказывающего» звука.
- Праздник (урок пройден, кристалл): 600–900мс, частицы, одна фраза Бита.
- `prefers-reduced-motion` — всё короче, без покачиваний.

### Музыка

Процедурная (пишется кодом, без файлов и лицензий), казахское фэнтези под лоу-поли небо. Код: `src/lib/music/`
(`tracks.ts` — ноты и разделы, `synth.ts` — голоса, `sequencer.ts` — планировщик), вход прежний: `audio.setMood(...)`.

| Настроение | Где | Звучит |
|---|---|---|
| `hub` | корабль, мастерская, герой, альбом | D дорийский, 6/8 (~67), 28 тактов ≈ 50 с. Дрон кобыза, арпеджио домбры, сыбызгы поёт мелодию, редкие колокольчики, в B и A' просыпается дойра |
| `map` | карта, диагностика, интро | A минор, 4/4, 108. «Конский галоп» домбры (доля = нота + две короткие), дойра, флейта, домбра-тремоло в A' |
| `battle` | бой | D минор, 4/4, 116. Остинато домбры 3+3+2, даулпаз и дойра, тремоло домбры, флейта и колокольчики, пауза перед возвратом |
| `victory` | итог | фанфар 4 с (D мажор), дальше тихо переходит в `hub` |
| `focus` | задача, урок | по настройке: «выкл» (секвенсор остановлен) или «тихо» (25 %) |

Чтобы петля не надоедала: разделы A/B/A'/хвост, у `hub` каждую вторую петлю мелодию ведёт домбра вместо флейты, случайные выпадения
нот и заполнения, ±6 мс живости. Микс: всё идёт через компрессор и мягкий ограничитель (пик < 0.95), музыка тише эффектов,
на голос Бита приглушается до 35 %. Слушать и записывать: `music.html` (dev-сервер). В режиме фокуса (задача, урок) музыка по умолчанию молчит.

## 10. Текст на экранах

- Кнопка = действие: «Бастау», «Тексеру», «Келесі», «Шайқасқа», «Ұшу». Не «Ок», не «Жіберу».
- Закрыто → причина и шаг: «Алдымен бүгінгі 2 тапсырманы орында».
- Ошибка → что делать: «Тағы ойлан: вагонда 3 орын». Ответ показываем только после второй ошибки.
- Числа, которые пугают («0 / 143»), не показываем; показываем ближайшую цель («Келесі костюмге 2 кристалл»).
- Экран командира (брат) — по-русски, детские — только по-казахски.

## 12. Как это работает (функциональный UX)

### 12.1 Карта переходов

```
                 ┌──────────── Интро (1 раз) → Диагностика (1 раз) ───────────┐
                 ▼                                                             │
        ┌──── КОРАБЛЬ (дом) ◄──────────────────────────────────────────────────┘
        │   главная кнопка = «следующий шаг дня»
        │
        ├─► Бүгінгі жол (путь дня, строго по порядку):
        │     1 Жылыну ─► 2 Жаңа тақырып (урок → практика) ─► 3 Аралас шайқас ─► 4 Қорытынды (награда)
        │
        ├─► Карта ─► мир ─► Ұшу / Босс
        ├─► Кейіпкер (характеристики, гардероб)
        ├─► Альбом (карты тем, шеберхана ошибок)
        └─► ⚙ Командир (PIN, брат, по-русски)
```

- Глубина максимум 2: из любого экрана «‹» возвращает на корабль (из урока/практики — через вопрос «выйти?»).
- На корабле **одна главная кнопка всегда ведёт к следующему шагу дня**. Ребёнку не нужно думать, куда нажать.
- Остальное (карта, герой, альбом, игра) — нижнее меню из 4 иконок с подписями, всегда на одном месте.

### 12.2 Главный цикл дня (будни, ~40 мин)

| Шаг | Что видит | Что делает | Что получает |
|---|---|---|---|
| Вход | Бит здоровается по имени; кольцо «Бүгін 0/4»; награда дня «до 60 мин» | жмёт главную кнопку | — |
| 1 Жылыну (6 мин) | 6 задач по старым темам вперемешку | решает | +минуты по доле плана, XP |
| 2 Жаңа тақырып (18 мин) | урок-миссия (бой с вирусом), потом 10 задач практики | учится | +минуты, карта темы в альбом |
| 3 Аралас шайқас (10 мин) | 8 задач вперемешку, реальные задачи экзамена | решает | +минуты, урон боссу мира |
| 4 Қорытынды | сколько заработал, что освоил, «что было трудно?» | отвечает 1 кнопкой | минуты зачислены, бонус-сюрприз |
| После | доп. миссии +15 мин (если брат разрешил) | по желанию | +15 мин за каждую |

Каждый шаг на корабле — карточка задания с наградой. Готовое — зелёное с ✓. Следующее — пульсирует.
Закрытое — с замком, при нажатии тост: «Алдымен: Жылыну».

### 12.3 Задача (практика, бой, диагностика) — 2 касания на ответ

1. Ребёнок читает условие на бумаге, касается варианта → вариант выделен голубым.
2. Внизу вместо одной кнопки появляются две: **«Сенімдімін ✓»** и **«Шамамен…»** (уверенность — для метакогниции,
   это и есть кнопка ответа). Передумал — касается другого варианта.
3. Ответ проверен:
   - **Верно** → зелёная плитка ✓, удар по врагу, «+10 XP», главная кнопка «Келесі» (зелёная).
   - **Неверно, первый раз** → коралловая плитка ✗, Бит объясняет *типичную ошибку этого варианта* (без ответа),
     вариант зачёркнут. «Тағы көр» — вторая попытка той же задачи. В модель знаний идёт **первая** попытка.
   - **Неверно, второй раз** → показан правильный ответ, решение на бумаге, правило темы; кнопка «Түсінбедім» (ИИ);
     главная «Реванш» — похожая задача с новыми числами.
4. **Подсказка** — кнопка-лампа рядом с главной, «0/3». Каждое касание — следующая ступень (вопрос → правило →
   первый шаг). После подсказки задача засчитывается слабее (как сейчас).
5. **Слишком быстро** (< 5 сек) — сразу мягкая строка «Асықпа — алдымен оқы», не в конце блока.

### 12.4 Урок-миссия

- Шапка: название миссии, «Қадам 3 / 11», полоса здоровья вируса.
- Тело: метка шага (Мақсат, Болжа, Қолмен, Көр, Өзің, Неге?, Қате, Ойын, Ереже) + бумага с содержимым шага.
- Главная кнопка меняется по шагу: «Миссияны бастау» → «Тексеру» → «Келесі». Неактивна, пока нет ответа;
  при нажатии на неактивную — тост «Алдымен жауап таңда».
- «Болжа»: после ответа — отдельная карточка «Неге?» с объяснением (ошибка не штрафуется).
- «Өзің» (пропуски): первая ошибка — подсказка; вторая — ответ.
- **Окно сцены** на шагах с заданием — `strip`, только `say` — `short`: задаче нужна высота. Всё, что можно, подгоняется под остаток высоты панели
  (`src/lesson/fit.ts`): 2D-сцена урока сжимается (`zoom`, не меньше 0.55), пицца в `FractionCircle` берёт размер из свободной высоты,
  `FillOne` сжимается не меньше 0.78. Цель — виджет и главная кнопка без прокрутки на 375×812 и 375×667; что не поместилось, прокручивается
  со стрелкой `.more` (её рисует Screen).
- **Горизонталь** (`html.lsplit`): реплика Бита не в карточке, а поверх окна сцены (`overlay` Screen, как в Session); карточка плотнее,
  пицца слева, кнопки справа.
- **Дроби этажные везде**: любой текст урока с «3/4» / «2 3/4» (вопросы, варианты, пропуски, правила, реплика Глитча, строки «Қате») выводится через
  `MathLine` (`inherit` — взять шрифт родителя). Разбор строки — `src/lesson/rich.ts` (`[..]` подсветка, `▢` пропуск, «:» и время не трогаем,
  числа с разрядами не рвутся). Реплика Бита (`Bit`) остаётся простым текстом: печатается по буквам.
- **Кнопка на бумаге** (Blitz «Тағы ойнау») — обычная синяя `.btn`; `.ghost` только на панели (белый по белому не читается). Пиксельный шрифт — только логотип.
- **Пропуск вместо перечитывания (D11)**: в каждом втором кадре «Көр» (среди тех, где есть подсвеченное число) и в «Есте сақта» одно ключевое число
  закрыто `▢`, под ним три варианта (`Gap.svelte`); верный открывает число с «поп», неверный гаснет, штрафа нет. Автоматически (`src/lesson/gap.ts`);
  отключить: `noGap: true` на кадре или на шаге. Число рядом со знаком сравнения не закрывается (подойдут и 7, и 9).
- **Читать действием (D12)**: пока «дальше» заряжается, подсвеченная часть `[..]` в кадре — кнопка: касание открывает «дальше» сразу; правильный
  вариант в пропуске делает то же. Таймер остаётся запасным.
  Шаг «Көр» этого больше не касается: он идёт как видео-объяснение без «дальше» (GAME_LOOP.md 21); D12 остаётся на шагах с заряжающейся кнопкой («Түсінбедім» и разбор ответа).
- «‹» во время урока → шторка «Миссиядан шығасың ба? Қай қадамда тұрғаның сақталады» → «Жалғастыру» / «Шығу».
  На корабле карточка задания показывает «Жалғастыру · 5/11».

### 12.5 Награды — всегда видно, откуда и сколько

- В шапке корабля 3 пилюли с подписью при первом показе: **минуты** (жёлтая), **кристаллы** (фиолет), **серия** (огонь).
- Когда что-то начислено — число «летит» в свою пилюлю, пилюля подпрыгивает.
- **Сцена награды одна на момент** (`src/lib/reward.svelte.ts`, `src/ui/RewardCard.svelte`): бонус посреди занятия кладётся в копилку
  (`queueReward`), в конце шага показывается ОДНА сцена со всеми пунктами (`showReward`): пункты появляются по очереди, цифры считаются
  вверх и монеткой влетают в счётчик минут, конфетти, звук. «Қабылдау» доступна сразу (читать нечего). Итог дня отдельного окна не
  имеет: награда — сам экран (цифры считаются, «+5» влетает в плитку).
- **Повышение уровня**: на корабле XP-полоска доезжает до конца, номер уровня вылетает крупно (луч, конфетти, звук), кнопка «Тамаша!».
  Минуты в пилюле корабля считаются вверх, если выросли с прошлого захода.
- Всплывающие надписи («+3 XP») рисуются чётко (без масштаба), никогда не лежат на кнопках и плитках: при попадании на нажимаемое
  переезжают в окно сцены.
- Кристалл = тема прошла отложенную проверку. Костюмы и порталы открываются кристаллами/энергией — на экране цели
  всегда «осталось N».

### 12.6 Состояния

| Состояние | Как выглядит |
|---|---|
| Закрыто | серое + замок; нажатие → тост с причиной и шагом |
| Пусто (альбом, журнал) | одна строка «что сделать, чтобы здесь появилось» + кнопка туда |
| Загрузка (ИИ) | кнопка «Бит ойланып жатыр…», неактивна |
| Нет интернета | всё работает, кроме ИИ; у ИИ строка «Интернет жоқ — ағаңнан сұра» |
| Выходной | путь дня скрыт; «Демалыс! Картаны ашу»; повторение по желанию без награды |
| Вернулся после пропуска | Бит: «Сені сағындық!»; серия спасена заморозкой или начинается заново — без упрёков |

### 12.7 Первый запуск

Интро 5 экранов (голос Бита) → диагностика: сверху «Сканер 7 / ~20», можно «Білмеймін», можно выйти и продолжить →
результат «Карта Кода» (какие зоны открылись) → корабль с первой миссией. Имя героя ставит брат у командира.

### 12.8 Брат (командир)

⚙ на корабле → PIN → по-русски: сегодня (минуты, трудное, вопросы к ИИ), подарок минут, исключения, темы, казахский
текст на проверку, облако. Ребёнок туда не попадает без PIN.
