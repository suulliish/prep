# C9: уравнения «x с двух сторон» и «скобки двумя способами» (заметки исполнителя)

Задача: MASTERPLAN §3 («весы → обратные действия → x с двух сторон → скобки двумя способами → составить по словам → проверка подстановкой»), спека content.md. Темы `eq.both_sides_nat` и `eq.brackets_nat` уже стояли в `content/queue.mjs` (декабрь), но не было ни узлов графа, ни генераторов, ни уроков: планировщик их пропускал.

Старые метки `eq2_stopped_midway` и `eq2_sign` используются повторно.

Ошибки в вариантах ответа (все варианты натуральные, ровно один корень):
- x с двух сторон: `eq2_stopped_midway` (не поделил), `eqb_x_sign` (x перенесён без смены знака), `eqb_const_sign` (число перенесено без смены знака), `eqb_one_coef` (поделил на число перед x только с одной стороны).
- скобки: `eqbr_first_only` (раскрыл скобки только у первого слагаемого), `eqbr_ignored_factor` (потерял число перед скобкой), `eq2_sign`, `eq2_stopped_midway`.
- задачи словами: коробки/копилки/весы (x с двух сторон); добавили в каждую / забрали из каждой / возраст через x лет (скобки). Условие в тексте задачи и уравнение в тесте разбираются независимо.

Сценарий урока: Мақсат → [Қолмен: виджет Scales, только у «x с двух сторон»] → Болжа → Көр → Өзің ×2 → Неге? → Глитчтің қатесі → Шағын ойын → Есте сақта → Соңғы сынақ. Для скобок готового виджета нет, шаг «руками» пропущен (новых виджетов не писал). Цель = финал (одна задача, в примере другие числа); ответ финала до финала нигде не назван результатом.

Виджет Scales (код прочитан): «зат» слева скрыт, гири можно ставить на обе чаши, готово при равенстве чаш. В уроке весы показывают состояние ПОСЛЕ снятия по 2 мешка с обеих чаш (4x + 5 = 2x + 17 → 2x + 5 = 17): «зат» = 12 г, гири 5 и 17; равновесие единственное (перебор 3^2 положений в тесте).
