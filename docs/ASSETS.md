# Готовые модели и анимации «Жарық»

Герои, монстры, острова, корабельный реквизит и анимации взяты из бесплатных паков с лицензией CC0 (список в `CREDITS.md`).
Корабль-база — готовый парусник Kenney с лётной оснасткой, собранной кодом (двигатели, кристалл подъёма, фонари). Портал, облака и летающие острова вокруг корабля тоже сделаны кодом, в том же мультяшном виде с контуром. Из кода также Бит, эффекты и мелочи.

## Как это устроено

```
исходные паки (вне репозитория) ──► scripts/assets/build.mjs ──► public/models/**.glb ──► src/three/*.ts
                                     (отбор, сжатие meshopt)      (в игру идёт только это)
```

| Что | Где | Зачем |
|---|---|---|
| Конвейер | `scripts/assets/` (`README.md`, `manifest.mjs`, `sets/*.mjs`) | отобрать нужное из паков, сжать в 2,5–3 раза, слить модели в наборы (`kit`) |
| Загрузка, единый вид | `src/three/assets.ts` | кэш, мультяшный материал и контур на все модели, `Kit.get(имя, {height, ground})` ставит на землю по габаритам |
| Актёры и анимации | `src/three/actor.ts` | `Actor` (модель + микшер), `createHero`, `createMonster`, `dress` (оружие в руки, скрыть части) |
| Герой на корабле и карте | `src/three/figure.ts` | `HeroFigure`: ходьба/стойка/радость, смена костюма |
| Костюмы | `src/three/looks.ts` | 8 костюмов = какой из 6 героев + оружие + оттенок |
| Враги по мирам | `src/three/roster.ts` | обычные мобы, мини-босс, босс мира для каждого из 12 миров |
| Остров боя | `src/three/island3d.ts` | плитки + декор; 6 раскладок «уголков» (по ролям) |
| Палитры миров | `src/three/worlds3d.ts`, `src/three/worlds/<номер>-<имя>.ts` | что стоит на местах с ролью «дерево», «ориентир» и т.д. в данном мире; свет, вода, кристаллы, доп. постановка кодом |
| Бой | `src/three/arena.ts` | пошаговый бой, катсцены, звуки на моменты удара |
| Портал | `src/three/portal.ts` | каменное кольцо с рунами, вихрь, искры; руны горят по энергии дня, `pulse()` — вспышка и волна. Один на корабле (с основанием) и в бою (в воздухе) |
| Летучий корабль | `src/three/airship.ts` | оснастка поверх парусника: двигатели с винтами и крыльями, кристалл под килем с лучом, кормовой винт, фонари, паруса в цветах игры. Ставится по габаритам корпуса, поэтому годится и для базы, и для кораблика на карте |
| Небо у базы | `src/three/skyscape.ts` | пухлые облака (два слоя) и летающие острова с деревьями из набора `isles` |

## Правила, которые не нарушать

1. **Земля и подошва — по габаритам.** Начало координат у моделей разное (у плитки KayKit оно на поверхности, у дерева и камня не у подошвы).
   `Kit.get(..., { ground: true })` ставит нижнюю точку на y = 0; землёй считается верх плитки. Так предметы не «летают».
2. **Собственное преобразование узла в наборе не сбрасывать**: в нём сжатие координат (квантование).
3. **Персонажи без квантования позиций** (`skinned: true` в конвейере), иначе контур по нормалям ломается.
4. **Только CC0.** Перед добавлением пака проверить лицензию на его странице и записать в `CREDITS.md`.
5. **Вес.** Набор мира до ~500 КБ. Миры и враги грузятся по требованию (при первом входе), дальше из офлайн-кэша.

## Как добавить…

- **Костюм:** строка в `looks.ts` (герой, оружие из `items`, что спрятать, оттенок). Тест `tests/models.test.ts` проверит, что всё существует.
- **Врага:** файл в `manifest.mjs` (раздел `monsters`), запись в `roster.ts`. Нужны клипы: Idle/Flying_Idle, атака, HitReact, Death.
- **Мир:** см. `scripts/assets/README.md`, раздел «Как добавить мир».

## Проверка

- `npm run dev`, затем `viewer.html` (модели, наборы, клипы, костюмы), `battle.html` (бой в любом мире, без входа и экранов) и `hub.html` (корабль-база: `?world=0..11&energy=0..1&q=low|high`, `&act=portalWalk` — катсцена входа в портал, `&cam=x,y,z,радиус,phi,theta` — камера вручную).
- Портал на палубе стоит лицом к обычному ракурсу камеры (`PORTAL_FACE` в `world.ts`); камера у базы не облетает корабль по кругу, а покачивается у этого ракурса, иначе паруса закрывают палубу.
- `npm test`: `tests/models.test.ts` сверяет костюмы, врагов, клипы и палитры миров с настоящими файлами в `public/models`.
