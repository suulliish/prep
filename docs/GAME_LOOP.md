# Игровой цикл «Жарық» v3 — как настоящая игра

29.09.2026. После первого дня игры: «мало анимации, герой стоит и машет; на карте домик, а герой на корабле — зачем портал;
разработай как реальную игру, а не одиночные анимации». Этот документ заменяет разделы 3, 7 и «карта миров» в `GAME_DESIGN.md`.
Учебная механика (урок → практика → отложенная проверка, BKT, повторения) не меняется — меняется то, во что она одета.

## 1. Жанр и образцы

| Образец | Что берём | Почему |
|---|---|---|
| **Prodigy Math** (RPG, 100+ млн детей) | пошаговый бой: верный ответ = твой ход-атака, ошибка = ход врага | жанр, где математика и бой — одно действие, проверен на этом возрасте |
| **Candy Crush / Duolingo** | карта-тропа из уровней, звёзды за уровень, следующий открывается после текущего | понятно «где я и что дальше», короткая сессия = один уровень |
| **Brawl Stars / Clash Royale** | «сочность»: цифры урона, тряска, частицы, комбо, суперудар, сундук, монеты летят в счётчик | каждое действие отвечает — это и есть «как в игре» |
| **Minecraft** | корабль-база, который растёт | дом, куда возвращаешься |

## 2. Главный цикл (одна сессия)

```
КОРАБЛЬ (дом)                      КАРТА-ТРОПА                           ЛОКАЦИЯ (уровень)
герой ходит по палубе,   ─►  точки-уровни мира, текущая  ─►  ПОРТАЛ: герой входит в портал на палубе,
Бит летает, портал светится   пульсирует, пройденные ★★★         вспышка → появляется на острове локации
        ▲                                                                  │
        │                                                                  ▼
   награды, сундук,                                            ВОЛНЫ ВРАГОВ (бой пошаговый):
   минуты, итог дня  ◄── ПОБЕДА: звёзды ★, сундук, монеты ◄──  урок = «разведка» (миссия Бита),
                                                               практика = 3 волны мобов, последняя — мини-босс
```

- **Уровень = одна тема** (или разминка/смешанный бой). Новая тема — новый уровень на тропе, в новом месте острова мира.
- **Мир = 8–12 уровней + босс мира.** Мир визуально свой (деревня, джунгли…), сама тема с миром не связана — мир это декорация, а
  тропа идёт по порядку учёбы.
- Корабль больше не арена боя. Бой всегда в локации. Корабль — дом: итог, награды, игровое время, гардероб.

## 3. Бой — пошаговый, как в Prodigy

Каждая задача — **ход**. Состояния боя (машина состояний, `src/three/battle.ts`):

```
ИНТРО ВОЛНЫ → [ХОД ИГРОКА: задача на экране] → ответ
   ├─ верно  → АТАКА ГЕРОЯ → ПОПАДАНИЕ → (враг жив) → следующий ход
   │                                    └ (враг повержен) → ДРОП → следующая волна / ПОБЕДА
   └─ неверно → АТАКА ВРАГА → ЩИТ ГЕРОЯ (блок, урона нет) → разбор → вторая попытка той же задачи
```

| Момент | Что видно и слышно (длительность) |
|---|---|
| Новая волна | враги выпрыгивают из разлома, баннер «2-толқын» (0.8 с) |
| **Новый вопрос** | карточка вопроса «перелистывается», номер «Сұрақ 4/8» вспыхивает, варианты влетают по одному; **ввод закрыт 0.7 с** — ребёнок видит, что вопрос новый |
| Выбор варианта | плитка подпрыгивает, герой поднимает оружие (замах = ожидание) |
| Верно | герой бежит к врагу (0.35 с) → удар (0.2 с) → вспышка, тряска камеры, **цифра урона** над врагом, враг отлетает и мигает белым → герой отбегает назад. Комбо-счётчик растёт, монета летит в счётчик |
| Серия 3 | **суперудар**: зарядка светом, прыжок, удар по площади, замедление времени 0.3 с |
| Неверно | враг атакует снарядом → герой ставит **щит**, искры, «Блок!» (никакого урона, никакого проигрыша) |
| Враг повержен | распад на кубики, выпадают монеты/кристалл, они летят в счётчик |
| Победа уровня | финальный удар, враги исчезают, **звёзды 1–3** (по точности с первой попытки), сундук открывается, награды по одной |

Задача на экране — спокойная (правило исследований про тревогу). Всё движение — между ответом и следующим вопросом, пока кнопки закрыты.

## 4. Экран задачи — вопрос и ответы вместе

- Окно сцены во время хода — узкая полоса боя сверху (герой и враг видны), панель — **условие закреплено сверху, варианты сразу под ним**, 2 колонки.
- Реплика Бита — поверх сцены (облачко), не сдвигает задачу.
- Каждая смена вопроса — перелистывание + номер + закрытый на 0.7 с ввод (п. 3).
- Ответ быстрее 5 с после появления вопроса не «обнуляет» миссию: этот один ответ не идёт в знания; Бит мягко говорит «асықпа».

## 5. Прогресс и экономика

| Ресурс | За что | На что |
|---|---|---|
| **Звёзды ★** (1–3 за уровень) | точность с первой попытки: 3★ ≥ 90%, 2★ ≥ 70%, 1★ — прошёл | открывают **сундуки мира** (каждые 10 ★) |
| **Монеты** | каждый верный ответ, повержённый враг | отсеки и украшения корабля (только красота) |
| **Кристаллы** | тема прошла отложенную проверку | костюмы (путь наград) |
| **Энергия Кода** | изученная тема | порталы в новые миры |
| **Минуты игры** | путь дня, доп. миссии (правила семьи) | игра только считает заработанное (счётчик «мин» на корабле, неделя — у командира); выдают время родители вне игры. Ни таймера, ни отдельного экрана нет (30.09) |
| **Награды за звёзды** | сумма звёзд всех уровней | след от оружия и цвет плаща (8 наград, от 3 до 45 ★; `STAR_REWARDS` в `content/worlds.mjs`) — мелкая косметика между большими скинами за кристаллы |

Сила героя не покупается ничем — только учёбой.

**Монеты (L5), цифры в `COINS` из `content/ship_items.mjs`:** верный ответ с первой попытки +2 (не даётся за «слишком быстрый» ответ по лесенке `rush.ts`, за полное решение (подсказка 4) и за вторую попытку; реванш и «егіз» считаются как обычные вопросы), побеждённый враг волны +5, бас жау мира +25 (при победе), 3★ за шаг дня +10 (один раз за шаг; каждая доп. миссия отдельно). Уровень на 8 вопросов и 3 волны при безошибочной игре ≈ 16 + 15 + 10 = 41 монета. Копятся в `save.coins`, за день — в `days[дата].coins` (итог дня). Покупки: `save.shipOwned`, активный питомец (один): `save.shipPet`.

## 6. Карта-тропа

- Карта мира — тропа из точек-уровней по острову мира (3D, `src/three/map.ts`): пройденные ★★★, текущая — пульсирует с героем рядом, дальше замки.
- Уровни на тропе = уроки тем в порядке учёбы + уровни-разминки/смешанные бои + босс мира в конце.
- Касание текущей точки → «Кіру» → катсцена: герой на корабле идёт в портал → вспышка → остров локации → бой.
- Мир пройден (босс) → портал в следующий мир, корабль перелетает.

## 7. Корабль живой

- Герой **ходит по палубе** между «станциями» (штурвал, портал, сундук, мастерская), стоит, осматривается, иногда машет Биту.
- Касание героя — реакция (прыжок, «Дайынмын!»). Касание портала — подсказка «Кіру → карта».
- После победы герой возвращается через портал и ставит трофей/сундук на палубу.

## 8. Доп. миссия (решение по умолчанию: вариант A из обсуждения 29.09)

10 задач: слабые темы + настоящие экзаменационные. Засчитана при **7 верных с первой попытки из 10**. Награда 15 минут.
Быстрые ответы (< 5 с) не идут в знания, но миссию не обнуляют.

## 9. Где сейчас «тропа уровней»

Тропа дня — список «Бүгінгі жол» на корабле: точки-уровни соединены пунктиром (пройденная часть зелёная), на пройденном
уровне — его звёзды. Звёзды хранятся за день (`DayRecord.stars`) и лучшие по теме (`Save.levelStars`). Касание уровня →
катсцена портала (герой идёт в портал на палубе, вспышка) → остров локации, герой входит, враг выпрыгивает. 3D-тропа из
точек на острове мира на карте — следующий шаг (L3b), сейчас карта показывает миры.

## 10. Нетерпение: «жмёт дальше, не читая» (30.09, наблюдение после первых дней)

Ребёнок пролистывает разборы. Правило: **после ошибки и на объяснениях кнопка «дальше» заряжается** на время чтения —
как перезарядка умения в играх, он этот язык знает. Полоса заполняется слева направо, подпись «Оқы…»; нажал раньше —
кнопка качается, Бит просит прочитать, разбор прокручивается в центр экрана. Время = 0.35 с на слово, от 2 до 9 с
(`src/lib/readgate.svelte.ts`).

- Бой: после первой ошибки (разбор ошибки Бита) и после второй (решение + реванш). На верный ответ зарядки нет — успех не тормозим.
- Урок: реплика Бита, правило, каждый новый кадр примера, пояснение после ответа на «почему/болжам».
- Проверка, что прочитал, — реванш: такая же задача сразу после разбора (уже было). Звёзды считают только исходные вопросы.
- **Пропуск в решении** (30.09, `src/engine/solgap.ts`): после второй ошибки в показанном решении одно число закрыто «?» —
  промежуточный результат шага («63 : 7 = ?») или средний класс в разборе числа («25 | ? | 647»). Ребёнок выбирает его из трёх;
  «Реванш» открывается только после верного выбора (+2 XP). Без чтения решения не ответить — это проверка понимания, а не ожидание.
  Если в решении нечего закрыть (текстовое решение), работает зарядка кнопки. На выгрузке шаблонов пропуск получается у ~3/4 решений.

## 11. Катсцены и скины (30.09: «сундук открылся, а он даже не заметил»)

Сценой управляет режиссёр (`src/three/arena.ts`): план камеры `shot()` (общий / крупный герой / враг / сундук) + постановка
движений героя. На время катсцены экран переходит в кино-режим (`Screen cinema`): шапка и панель задачи уходят, сцена на весь
экран, чёрные полосы сверху и снизу.

| Катсцена | Что происходит |
|---|---|
| Вход в локацию | портал в воздухе → герой вылетает по дуге, приземляется (пыль, сплющивание) → крупный план, осматривается |
| Появление врага | разлом в земле → враг выпрыгивает → рык, герой встаёт в стойку. Мини-босс: тряска земли, красная волна, надпись «МИНИ-БОСС» |
| Удары | обычный — подбег и замах; серия — удар с разворота; суперудар — зарядка, прыжок, удар по земле, замедление. Добивание — крупный план и замедление |
| Ошибка | снаряд врага → щит, герой отшатывается |
| Победа | поза с разворотом и мечом вверх → сундук падает с неба → герой замечает, подходит, приседает, крышка дрожит и открывается (столб света, монеты) → герой прыгает и радуется в камеру |
| Возврат | на палубе вспыхивает портал, герой выходит из него и идёт на палубу |

Скины (`src/three/gear.ts`) — не перекраска, а экипировка из кубиков: головной убор, оружие, плащ (качается при ходьбе),
щит, у редких — сияние вокруг героя. Одеваются все герои: палуба, карта, бой.

| Костюм | Экипировка |
|---|---|
| Кодер | визор, меч-ключ |
| Алтын | корона, большой меч, щит, красный плащ |
| Неон | неоновые наушники, катана, светящийся плащ |
| Орман | капюшон с листом, топор, деревянный щит, зелёный плащ |
| Жалын | рогатый шлем, огненный меч, огненный плащ |
| Аяз | ледяная корона, копьё, ледяной щит, белый плащ |
| Бос кеңістік | капюшон со звёздами, коса, звёздный плащ, сияние |
| Кристалл | парящая кристальная корона, кристальный меч, щит, сияние |

## 12. Тема = свой уголок мира (30.09)

Внутри мира у каждой темы свой уголок (`src/three/spots.ts`): 6 композиций острова — алаң, үстірт (плато), көл (пруд с мостиком),
орман (роща), қирандылар (руины с аркой), кристалдар — и своё время суток: день, закат, ночь с фонарями. Цвета и ориентир мира
остаются, мир узнаваем. Уголок выбирается по id темы (одна тема — всегда один уголок: и урок, и практика); разминка и смешанный
бой — уголок дня. На входе — облёт камеры сверху и баннер «Мир · Уголок».

## 15. Против спешки в бою (30.09, D2, D3, D5 из `night/research-learning.md`)

Ребёнок отвечает раньше, чем замечает, что вопрос сменился. Три механики, все без штрафов к XP и минутам: это про внимание.
Логика в `src/engine/rush.ts` (пороги и тесты `tests/rush.test.ts`), очередь вопросов в `planner.ts` (`tests/planner_interleave.test.ts`), показ в `Session.svelte`.

| Механика | Что делает |
|---|---|
| **Подсветка изменений (D3)** | новое условие сравнивается с прошлым по словам: числа и слова-ключи («ең кіші/ең үлкен», «артық/кем», «неше/қанша», единицы), которых там не было, вспыхивают жёлтым 0,8 с и остаются с мягким подчёркиванием. Совсем другой вопрос (общих слов < 30%) — подсвечиваются только слова-ключи, числа не (шум). Верный вариант не стоит на том же месте (A–E), что в прошлом вопросе: его меняют местами с другим, `answer` и метки ошибок едут вместе; не трогаем числа «по порядку», «барлығы дұрыс», «A және B» и настоящие задачи банка |
| **Лесенка быстрых ответов (D2)** | «слишком быстро» = быстрее 2,0 с + 0,04 с × знаков условия (не меньше 2,5 с, не больше 8 с), без подсказок; считается первая попытка, реванш не считается. 1-й: Бит «Асықпа!». 2-й подряд: «егіз» (тот же шаблон, новые числа) вернётся через 3 вопроса (в конце боя — на последнем; после последнего не возвращается), «егіз» занимает место вопроса и считается как обычный. 3-й и дальше: на следующем вопросе 3 с спокойной паузы и мини-проверка «Сұрақ не туралы?» (3 варианта вида вопроса: пайыз, уақыт, жылдамдық…), пока не ответит, варианты ответа закрыты; вид вопроса не распознан — кнопка «Оқыдым». Ответ после проверки и любой обычный обнуляют серию. Быстрый ответ пишется в попытку флагом `fast` (старые сохранения без поля читаются как раньше) |
| **Чередование (D5)** | очередь боя (`sequenceSlots`): темы по кругу, внутри темы шаблоны так, чтобы два вопроса одного шаблона не шли подряд и шаблоны использовались поровну. Смешанный бой берёт тем сколько есть (в плане дня их не меньше 3, если пройдено ≥ 3). Исключения: тема с единственным шаблоном без других тем; реванш после ошибки нарочно берёт тот же шаблон с новыми числами |

Существующая отметка «нечестный ответ» (быстрее 5 с, не идёт в знания, п. 4 и 8) не менялась: она про модель знаний, лесенка — про внимание.
Время ответа отсчитывается с момента, когда вопрос можно решать (после 0,7 с закрытия и после анимации входа в локацию).


## 16. «Глитчтің қатесі»: ход боя «найди чужую ошибку» (30.09, D8)

Раз в ~5 вопросов вместо вопроса Глитч «решает» ту же задачу на экране: 3–5 строк, одна портится. Ребёнок нажимает первую неверную строку. Основание: разбор чужих ошибок ([Booth 2013](https://files.eric.ed.gov/fulltext/ED543090.pdf)), в уроках это уже шаг `bug`.
Логика в `src/engine/glitchturn.ts` (тесты `tests/glitchturn.test.ts`), вид `src/ui/GlitchTurn.svelte` (тот же язык, что `GlitchSays` + `BugHunt`), ход боя `Session.svelte` (`glitchTap`).

| Что | Как |
|---|---|
| **Откуда строки** | готовый разбор шаблона (`sol.kz`) делится на строки: предложения и «;», при нехватке цепочки «a = b = c» и «пояснение: выкладка». Больше 5 склеиваются. Шаблон, из разбора которого не выходит 3 строк, ходов не даёт (тогда обычный вопрос) |
| **Как портится** | результат (верный ответ) в строке заменяется ответом-ловушкой шаблона с **настоящей меткой ошибки** из `content/misconceptions.mjs` (метки «random», «arith» без разбора не берутся); дальше он же повторяется в следующих строках как следствие. Результата в разборе нет — в конец добавляется «Жауабы: …». Число ловушки, которого нет в разборе, предпочитается |
| **Когда выпадает** | не в первых двух вопросах; первый ход на 3–5-м вопросе, следующий через 4–6 (в среднем раз в 5, подряд не бывает); только по навыку, который уже решали ≥ 2 раз; не вместо реванша, «егіз», мини-проверки и настоящей задачи экзамена; в босс-бою не на последнем вопросе и не когда следующий удар может добить босса (`mobHp ≤ 2` последней волны) |
| **Верно** | контрудар (`heroAttack`, всегда с «критом»; серия 3 — суперудар), XP как за верный ответ, Бит одним предложением объясняет ошибку (первое предложение из `MISCONCEPTIONS`) |
| **Неверно** | атака врага, как за обычную ошибку; неверная строка помечена «ҚАТЕ», под ней «Дұрысы: …»; нажал на строку-следствие — «ол да қате, бірақ ошибка раньше»; Бит читает полное объяснение, открывается «Шешуі» с пропуском (как после обычной ошибки), кнопка «дальше» заряжается; после хода — реванш: обычная задача того же шаблона с новыми числами. В «мастерскую» не попадает (это разбор чужого решения, а не своё) |
| **В модель знаний** | обычная попытка навыка (BKT видит верно/неверно), с флагом `kind: 'glitch'`; метка неверной попытки — метка ловушки, если нажал на строку-следствие, иначе `glitch_miss` |
| **Против спешки** | ввод закрыт 0,7 с, строки влетают по одной; «слишком быстро» = порог п. 15 на длину условия **плюс** всех строк; быстрый ход идёт в ту же лесенку (асықпа, егіз, пауза с вопросом) |
| **Dev** | `?glitch=1` (только `import.meta.env.DEV`): ход на каждом вопросе, где его можно собрать, без правил частоты |

Известное ограничение: строка портится подстановкой готового неверного ответа шаблона, а не пересчётом шага, поэтому арифметика в неверной строке может быть «дикой» (например «11 + 27 = 60»), а метка объясняет причину неверного ответа, а не арифметику строки.
