# D2: минуты по новому правилу в тени

Спека: `docs/systems/specs/day.md` (PR D2), `IMPLEMENTATION.md` §1.1–1.3. Прототип расчётов: `docs/systems/proto/minutes_proto.mjs`.

## Что есть
- `src/engine/minutes.ts`: чистый движок (слоты, долги, полоса, ремонт, «застрял», честное время, начисление, доп. миссия, копилка, слияние двух устройств). Числа: `content/balance.mjs` (`MIN`).
- `src/engine/rules.ts`: `classify(f)` (чем ответ стал для минут), рядом с `isHonest`, `isRushed`, `isClosed`.
- `src/engine/minutesShadow.ts`: «тень». `shadowAnswer` вызывается из `Session.svelte` после каждого `recordAttempt` (3 места), пишет в `days[день].mins` и `save.debts`. `shadowSummary` читает строку для командира.
- `src/screens/commander/MinutesShadow.svelte` в «Сегодня»: «По новому правилу (тень): 47/60, долг 6, честного времени N мин; по старому: M».
- Слияние: `mergeDay` (поле `mins`) и `mergeSave` (поле `debts`, запись в `MERGE_RULES`) в `sync.ts`.

## Решения, принятые внутри тени (проверить перед D7)
- Слот ответа: id = `день|время ответа|тема|шаблон` (одинаков на любом устройстве). Слоты спеки `${day}:${trip}:${step}:${i}` появятся с рейсами (D6).
- Слот плана — ответ в разминке, новой теме, смешанных. «Егіз» (близнец) и бой «Ремонт» — не слоты, а ремонт: честный верный близнец закрывает первый открытый долг той же темы, неверный ничего не отнимает. Босс в минуты не входит. Доп. миссия считается отдельно (`mins.extra`, 10 задач), долгов не заводит.
- Верный с подсказкой ≥ 2 и полный разбор (любой ответ) = «Білмеймін» (0, 1 близнец). «Білмеймін» быстрее 1,5 с = наспех. Неверный наспех остаётся неверным (−¼, 2 близнеца), просто не даёт честного времени.
- «Білмеймін» на всё: больше 6 за день, за каждое по 2 близнеца (не зависит от порядка ответов, поэтому одинаково на двух устройствах); такие долги в конце очереди.
- planN: сумма задач плана дня (`rec.plan`), иначе 24.
- Попыток ремонта не больше 2 в день считается только у перенесённых долгов. Перенос: ≤ 8 близнецов, долг живёт 2 учебных дня.
- Честное время в тени: только задачи боя (урок, разбор, «Еске түсір» и правило «45 с без касаний, часы стоят» пока не подключены, это D7). Предел одной задачи: min(180 с, max(45 с, 3 × медиана верных по теме)).
- Начисление (`credit`, `applyCredit`) в тени не пишется: `mins.credit` остаётся пустым, день виден только как полоса и «было бы начислено».
