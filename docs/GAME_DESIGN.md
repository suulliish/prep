# Игровой дизайн: RPG «Хранители Алтая» (рабочее название)

Игрок: 11 лет, играет в Minecraft, Roblox, Sneaky Sasquatch, Brawl Stars.
Жанр: пиксельное RPG с исследованием мира, стройкой базы и коллекцией героев.
Учебная часть — в `ARCHITECTURE.md`; здесь — как она выглядит для игрока.

Главный принцип: **всё, что есть у героя, отражает реальные знания.** Герой сильнее — значит брат умеет больше. Никакого «фарма» без учёбы и никаких наказаний за ошибки.

## 2. Мир: Восточный Казахстан

Действие — в сказочной версии родного края: Алтай, Иртыш, Бухтарма, Катон-Карагай. Свой край узнаётся и вызывает интерес.

Сюжет: Хаос-туман окутал Алтай, числа и законы логики перемешались. Хранители восстанавливают порядок — регион за регионом.

**Наставник — снежный барс Барыс**: ворчливый, смешной, любит бауырсаки. От его имени идут заготовленные уроки; кнопка «Не понял, объясни по-другому» — тоже Барыс.

Регионы (разделы программы) — **пример, уточним по графу навыков**:

| Регион | Темы |
|---|---|
| Деревня Натуральных чисел (стартовая) | действия, порядок действий, степени |
| Лес Делимости | признаки делимости, простые числа, НОД, НОК |
| Королевство Дробей на Иртыше | обыкновенные дроби, все действия |
| Десятичные пещеры | десятичные дроби |
| Горы Процентов | проценты, части от числа |
| Озеро Движения (Бухтарма) | задачи на движение, работу |
| Тёмная сторона (отрицательные числа) | рациональные числа, модуль |
| Крепость Уравнений | выражения, уравнения, неравенства |
| Долина Фигур | углы, периметр, площадь, окружность |
| Земли Пропорций | отношения, пропорции, масштаб |
| **Башня Логики** (отдельно, этажи вверх) | один этаж = один тип логических задач |
| **Арена КТЛ** | пробные экзамены |

Карта: 2D пиксельная, вид сверху. Туман закрывает локации, пока не освоены предки в графе навыков. Следующая локация видна, но заперта — «что там?» тянет вперёд.

## 3. Герой

### 3.1 Создание
Имя, внешность (пиксельный аватар из частей: голова, одежда, аксессуар). Позже открываются новые части.

### 3.2 Характеристики — считаются из реального прогресса

| Характеристика | Откуда |
|---|---|
| ⚔️ Сила чисел | освоенные навыки арифметики, дробей, процентов, уравнений |
| 🧠 Мудрость | освоенные этажи Башни Логики |
| 🎯 Меткость | точность без подсказок за последние 2 недели |
| ⚡ Скорость | темп в экзаменационном режиме (открывается в 2028) |
| 🛡️ Стойкость | серия учебных дней |

Их нельзя «вкачать» кликами — только научившись.

### 3.3 Уровень героя
Растёт от XP. XP — за самостоятельно решённые задачи: без подсказки больше, с подсказкой меньше, после полного разбора — 0.

### 3.4 Путь знаний (аналог пути трофеев)
Одна длинная дорога с наградами на отметках — по числу **освоенных навыков** (не решённых задач). Видно, сколько до следующей награды и сколько до «готов к экзамену».

## 4. Коллекция героев-спецов (как бойцы в Brawl Stars)

За прохождение региона открывается **новый герой-спец** — персонаж с суперспособностью, связанной с темой:

| Спец | Открывается | Суперспособность в бою |
|---|---|---|
| Дробина | Королевство Дробей | удар ×2 по задачам с дробями |
| Процентник | Горы Процентов | снимает щит босса на задаче с процентами |
| Скороход | Озеро Движения | бонус на задачах на движение |
| Логик | каждые 3 этажа Башни | «подсказка без штрафа» 1 раз за бой на логике |
| … | | |

В бою босса выбираешь, каким спецом идти. Выбор — автономия; сила спеца зависит от освоенности его темы (карточки навыков, см. ниже).

**Карточки навыков**: каждый освоенный навык = карточка с 3 ступенями (изучено → освоено → автоматизм). Карточки «заряжают» спецов своей темы. Когда навык созревает для повторения, карточка тускнеет — повтори, и она снова сияет.

## 5. База (как в Minecraft)

У героя есть свой участок у подножия Белухи, который он застраивает.

- **Ресурсы** выпадают за самостоятельно решённые задачи в регионе: дерево в Лесу Делимости, рыба и вода у Иртыша, камень в Горах, кристаллы в Пещерах, магия в Башне Логики.
- **Постройки** из ресурсов: дом, кузница, библиотека, конюшня, обсерватория, мост… Каждая постройка — видимый след пройденного пути.
- **Особые постройки** — только за вехи: трофейный зал (за боссов), статуя (за освоенный регион), флаг лицея (за пробник выше цели).
- Постройки **не дают силы в боях** — только красота и гордость. Чтобы база не превратилась в гринд.
- Когда навыки просрочены для повторения, на постройках региона появляется «туман» — повторение его сдувает. Ничего не разрушается.

## 6. Бои с боссами

- В конце региона — босс. Бой: 10–15 задач **вперемешку** из всех тем региона (чередование).
- Верный ответ — удар (сила зависит от спеца и его карточек). Серия верных — суперудар.
- Неверный ответ — босс не получает урон, **герой ничего не теряет**. Показывается разбор ошибки.
- Бой короткий, 8–12 минут, как матч.
- Не добил — завтра снова, с другими задачами; прогресс HP босса сохраняется частично.
- Победа → сундук: новый спец/облик/карточка; иногда — **неожиданные бонусные минуты игры** (+10–15).

Мини-боссы: «монстры вернулись» — короткие бои-повторения в пройденных локациях (разминка дня).

## 7. Квесты и сезоны

| Что | Как выглядит | Что на деле |
|---|---|---|
| Ежедневный квест | 3 задания от Барыса | дневной план: разминка, новое, смешанное |
| Недельный квест с братом | общая цель: 5 учебных дней | награда — реальная совместная (играете вместе, выбираете фильм…) |
| Сезон (= четверть) | сюжетная глава, сезонный путь наград | темы четверти; финальный босс сезона |
| Испытания | «10 задач на движение без подсказок», «босс без единой подсказки» | только за умения, не за вход |
| Секреты (как в Sneaky Sasquatch) | спрятанные на карте головоломки | олимпиадные/логические задачи повышенной сложности, по желанию |

## 8. Арена КТЛ

- Пробные экзамены в формате 60 вопросов / 110 минут / +4 −1 (с января 2028); до этого — мини-турниры по пройденному.
- Соперник — **«призрак» самого себя**: прошлый результат. Никаких рейтингов с чужими.
- После турнира — разбор: где терял баллы, где угадывал удачно/неудачно, где не хватило времени.
- Трофей арены растёт с результатом; цель на экране — проходной уровень.

---

## 9. Экономика

Только две «валюты», чтобы не было путаницы и фарма:

1. **XP** → уровень героя.
2. **Игровое время** (реальные минуты) — по правилам из `ARCHITECTURE.md`, раздел 9.

Плюс ресурсы базы (только на постройки, без влияния на бои).
Облики, спецы, особые постройки — **только за вехи**, не покупаются ни за что.

---

## 10. Чего не будет (по исследованиям вредит)

- смерть героя, жизни и сердечки, потеря прогресса за ошибки;
- лутбоксы, случайные награды за время;
- рейтинги с чужими людьми;
- награды за «просто зашёл» или за просиженное время;
- давление на вину («питомец умирает», «Барыс плачет»);
- гринд: сила в бою не покупается ресурсами.
