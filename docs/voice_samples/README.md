# Образцы голоса Бита (казахский синтез речи)

Сгенерировано бесплатным офлайн-движком **Piper** (открытый код) с казахскими голосами проекта **ISSAI KazakhTTS** (Назарбаев Университет): модели `rhasspy/piper-voices` → `kk/kk_KZ`.

Текст всех образцов:
> Сәлем! Мен Битпін. Глитч бөлшектерді бұзып кетті. Мына жолақты төрт тең бөлікке бөліп көрші! Жарайсың, дәл таптың: төрттен үш қосу сегізден бір — сегізден жеті.

| Файл | Голос |
|---|---|
| `bit_issai_0.mp3` … `bit_issai_5.mp3` | ISSAI high, 6 разных дикторов (лучшее качество) |
| `bit_issai_0_robot_higher.mp3` | диктор 0, чуть выше и быстрее — «роботный» Бит |
| `bit_iseke.mp3`, `bit_raya.mp3` | облегчённые голоса (x_low), качество ниже |

Как будет работать: реплики Бита озвучиваются заранее при сборке сайта (скрипт), файлы лежат рядом с сайтом — интернет и платные сервисы не нужны. Числа в репликах пишутся словами. Если какое-то слово звучит неправильно — меняем написание.

**Выбрано 27.09.2026:** `bit_issai_0_robot_higher` — диктор 0, «роботный» вариант. Настройки — `content/voice.json`, озвучка — `scripts/voice/make_voice.py`.
