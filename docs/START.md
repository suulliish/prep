# Как начать (для брата-командира)

## Где открыть
- **Сейчас:** превью-ссылка на claude.ai (её можно открыть с любого устройства, где вы вошли в claude.ai,
  или поделиться через меню Share). Прогресс хранится в браузере этого устройства; облако в превью не работает —
  раз в неделю скачивайте копию: шестерёнка → «Данные» → «Скачать копию прогресса».
- **Постоянный адрес:** `https://suulliish.github.io/prep/` — после слияния ветки в `main` и включения
  Settings → Pages → Source: GitHub Actions. Там работает облако (вход по ссылке на почту) и установка на экран «Домой».
  Не забыть: Firebase → Authentication → Settings → Authorized domains → `suulliish.github.io`.

## Первый запуск (10–15 минут)
1. Экран «РАЗЛОМ» → «Ойынды бастау» — Бит голосом рассказывает историю (5 экранов). Включите звук.
2. Код-сканер: 10–20 задач. Не знает тему — пусть жмёт «Бұл тақырыпты әлі білмеймін», это нормально.
3. Корабль → квест «Жаңа миссия» → урок-бой (10–15 мин) → практика (10 задач).
4. «Бортжурнал» — итог дня: минуты игры.

## Каждый будний день (~35–40 минут)
Разминка-повторение → новая тема (урок + практика) → смешанный бой → итог. За план — до 60 мин игры сегодня и до
48 мин в копилку выходных (на экране корабля копилка показана до 90); после плана — доп. миссии по +15 мин (лимит в настройках).
Минуты как на экзамене: верный ответ +1, неверный −¼, «Білмеймін» 0. Ответ быстрее порога (2,5-8 с, зависит от длины условия)
в минуты не идёт. Свернул приложение на задаче дольше 5 секунд, или вышел из боя с открытой задачей: задача закрывается
и считается ошибкой, следом идёт близнец. Пропусков нет. Правила для ребёнка: «Ойын заңдары» на экране героя.

## ИИ-помощник Бит («Түсінбедім»)
После ответа на задачу, если непонятно, ученик жмёт «Түсінбедім — Биттен сұра»: Бит (Gemini через Vertex, как у бота)
объясняет иначе и отвечает на 3 уточняющих вопроса. До ответа ИИ не помогает — так задумано (исследования).
Работает только после входа в облако на этом устройстве (командир → «Данные»). Все вопросы и ответы — во вкладке
командира «Вопросы к ИИ». Подробности: `helper/README.md`.

## Командир (шестерёнка вверху справа, PIN)
Сегодня: минуты, что было трудно, исключения дня (болел/праздник). Подарков и бонусов нет (решение 02.10), каникул нет: учёба все будни.
Настройки: имя героя, лимит доп. миссий, звук. Темы: карта прогресса. Казахский текст: очередь проверки уроков.
Данные: облако, копия в файл.

## Что готово
15 уроков-миссий (3 недели): разряды, деление с остатком, порядок действий, степени, признаки делимости,
простые числа, разложение, НОД, НОК, задачи на НОД/НОК, кратные, цифра вместо звёздочки, число квадратов/кубов,
множества, круги Эйлера. Дальше новая тема появляется только с готовым уроком — иначе день повторения.
