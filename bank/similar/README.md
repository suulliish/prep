# Похожие задачи: разбор «Дарын» 2023 и генераторы

Пилот на одном реальном тесте: все 55 задач по математике и логике «Дарын» 2023 разобраны, и почти для каждой написан **генератор** — код, который делает бесконечно много задач того же типа с новыми числами, на казахском и русском.

- Код: `content/templates/*.mjs` (50 шаблонов).
- Проверка: `node scripts/check-templates.mjs 2000` — каждый шаблон 2000 раз: 5 разных вариантов ответа, ровно один верный, нет пустых/NaN, есть решение, достаточно разнообразия. Сейчас: **50 из 50 без ошибок**.
- Образцы: `daryn2023_samples.md` — по 3 задачи на каждый шаблон с ответом, меткой каждой ошибки и решением (`node scripts/sample-templates.mjs 3`).

## Как устроен генератор

1. **Условие — по формулировке оригинала.** Казахский текст взят из PDF «Дарына» (`bank/sources/daryn_7_2023.pdf`), меняются числа, имена, предметы. Падежные окончания после чисел и имён (189-ға, 40-қа, Саматтың, Марат пен) ставятся автоматически.
2. **Ответ вычисляется кодом точными дробями** — без округлений и без участия ИИ.
3. **Неправильные варианты — типичные ошибки**, а не случайные числа: забыл перевести единицы, сложил проценты вместо концентраций, забыл про модуль, потерял целую часть смешанного числа, ответил на другой вопрос (промежуточный результат). У каждого варианта есть метка ошибки → сайт сможет показать разбор именно этой ошибки.
4. **Решение на двух языках**, коротко, по шагам.

## Что дальше

1. «Дарын» 2024 и Bolashak 1–2: те же шаги — сначала сопоставить с готовыми шаблонами (многие типы повторяются), новые типы — новые генераторы.
2. «Дарын» 2025 — отложен как честный пробник (holdout). Генераторы по его *типам* делать можно, но сами задачи в тренировку не попадают.
3. Рисунки: SVG для углов, сеток, фигур; 3D для кубов и развёрток.
4. **Проверка казахского текста носителем** — обязательна до показа ученику: окончания проверены кодом, но формулировки — мои.
