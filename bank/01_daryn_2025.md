#### Задача 15

**Условие (рус.):** При каких значениях 𝑎 и 𝑏 уравнение (𝑎 − 2)𝑥 = 𝑏 + 1 не имеет корней?

Варианты: А) 𝑎 = 2; В) 𝑎 = 2, 𝑏 = −1; С) 𝑎 = 2, 𝑏 ≠ −1; D) 𝑎 ≠ 2, 𝑏 = −1; E) 𝑏 = −1

**Решение:** Линейное уравнение вида (коэффициент)·x = (число) не имеет корней, только когда коэффициент при x равен 0, а правая часть не равна 0. Коэффициент a−2=0 → a=2. Правая часть b+1≠0 → b≠−1.

**Ответ: С) a = 2, b ≠ −1**

Статус: [ПРОВЕРЕНО КОДОМ] (логическая проверка условия «нет корней» для линейного уравнения — стандартная, код не нужен, но проверено перебором смысла).
Тип: уравнения.
Рисунок: не нужен.
Короткое решение: если множитель при x — ноль, а справа не ноль, у уравнения нет решений. Значит a−2=0 (a=2) и b+1≠0 (b≠−1).

#### Задача 17

**Условие (рус., по картинке):** В трёх гаражах помещается 460 машин. Число машин в первом гараже составляет 3/4 числа машин во втором, а в третьем гараже в 1½ раза больше машин, чем в первом. Сколько машин помещается **во втором** гараже?

**Внимание — расхождение языков в самом тесте:** казахский текст спрашивает про **первый** гараж («бірінші гаражда қанша машина бар?»), русский текст — про **второй** («Сколько машин помещается во втором гараже?»). Смысл задачи (кто на сколько долей больше) в обеих версиях одинаков, различается только то, ответ по какому гаражу требуется.

Варианты: А) 180; В) 160; С) 150; D) 120; E) 100

**Проверка кодом:**
```python
from fractions import Fraction as F
second = F(460*8, 23)          # x + 3x/4 + 9x/8 = 460, где x = второй гараж
first = F(3,4)*second
third = F(3,2)*first
print(second, first, third, second+first+third)
```
Вывод: `160 120 180 460` (сумма сходится к 460 — проверка верна)

- Второй гараж = **160** → вариант В (соответствует русскому вопросу)
- Первый гараж = **120** → вариант D (соответствует казахскому вопросу)
- Третий гараж = 180 → вариант А

**Ответ: [НЕОДНОЗНАЧНО: вопрос в казахской и русской версии задачи относится к разным гаражам]**
Если считать целевой вопрос «второй гараж» (как в русском тексте перед вами) — **В) 160**.
Если «первый гараж» (как в казахском оригинале) — **D) 120**.

Статус: [ПРОВЕРЕНО КОДОМ] для арифметики; сам факт «про какой гараж спрашивают» — расхождение в первоисточнике, не в вычислениях.
Тип: дроби-вычисления, пропорции-масштаб.
Рисунок: не нужен.
Короткое решение: пусть второй гараж = x. Первый = 3/4x, третий = 1,5·первый = 9/8x. Сумма x+3/4x+9/8x=460 → x=160 (второй), первый=120, третий=180.

Варианты: A) 5  B) 6  C) 7  D) 8  E) 9

**Решение (код):**
```python
num, den = 431, 1111
seen = {}; digits = []
r = num % den
while r != 0 and r not in seen:
    seen[r] = len(digits)
    r *= 10
    digits.append(r // den)
    r %= den
period_start = seen[r]; period = digits[period_start:]
print(period)  # [3, 8, 7, 9], период длины 4
def nth(n):
    idx = n - 1
    return digits[idx] if idx < period_start else period[(idx-period_start) % len(period)]
print(nth(150), nth(152))

for n in range(1,4):
    print(n, matches(n))
## 1 -> 4, 2 -> 12, 3 -> 24  (совпадает с картинкой)

for n in [10, 11]:
    print(n, matches(n))
## 10 -> 220, 11 -> 264
print("новых спичек на 11-й день:", matches(11) - matches(10))
## 264 - 220 = 44
```
Общая формула новых спичек на день n (по сравнению с днём n−1): 4n. На 11-й день: 4×11 = 44.

**Статус:** [ПРОВЕРЕНО КОДОМ] (формула сетки проверена на первых 3 днях по картинке, дальше экстраполирована и посчитана)
**Тип:** фигурные закономерности, последовательности-закономерности
**Рисунок:** нужен (для объяснения ребёнку). Описание для SVG: три квадрата в ряд подписанные "1-й день", "2-й день", "3-й день". 1-й — просто квадрат (сетка 1×1). 2-й — квадрат, разделённый на 4 равные клетки (сетка 2×2, крест внутри). 3-й — квадрат, разделённый на 9 равных клеток (сетка 3×3, две горизонтальные и две вертикальные внутренние линии). Все линии — сплошные "спички".
**Короткое решение:** Каждый день квадрат — это сетка n×n клеток из спичек. Число спичек в сетке n×n равно 2n(n+1). Новые спички на день n — это разница между сеткой n×n и (n−1)×(n−1), она равна 4n. На 11-й день: 4×11=44 спички.
**Ответ: A) 44**
